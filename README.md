# Libunit

## Description
Test framework that allows to test C programs.
Main features:
-	Easy to setup test, using a helper script that generate C code
-	Easy to configure test, modifying a configuration file generated by the script
-	Every test is run in a separate process
-	STDOUT/STDERR management
-	signals management (SIGSEGV, SIGILL, ...)
-	Safe test backup when changing configuration file

## Warnings

1)	Your main function will not be used.
	So the functions you want to test MUST BE indepentent from main.

## How to use
1)	install
```bash
git clone -b tester [URL] && cd libunit
```
2)	check that the tester works properly
```bash
make && make check_tester ; make fclean
```
3)	run first time to initialize: it will create "setup_test.ini"
```bash
make generate
```
4)	modify the file following the comments.
	The only mandatory flag is obj: the root dir of the .o of your program.

	A module is a part of your program you want to test.
	So, for example, if you want to test your string.h implementation, 
	this would be a valid configuration file:
```ini
@obj:./

$strlen
[
	single_char
	empty_string
	null
	long_string
]

$strcat
[
	single_char_to_single_char
	empty_str_to_single_char
	single_char_to_empty_str
	empty_str_to_empty_str
	long_str_to_single_char
]

$strcmp
[
	equal
	different
	null
]

```
5)	a directory named real-tests will be created, with the C code generated.
	now, it's time for you to edit those test.
	Remember that by default the tester expects the functions to return 0.
	You can change this behaviour editing the flag 'expected_output'.

6)	run one of the following commands to test your program:
```bash
make test	#	normal testing
make val	#	tests using valgrind
```

7)	have fun debugging your code.
	experiment with the flags for advanced usage.
